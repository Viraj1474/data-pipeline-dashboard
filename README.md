📊 Data Pipeline Dashboard Project

Data Pipeline Dashboard is a Python and Streamlit project that demonstrates a full ETL (Extract, Transform, Load) process, interactive data analysis, and visualization. It allows users to upload or generate sample data, process it through ETL scripts, and visualize insights through charts, tables, and automated reports.

🌐 Live Demo (Local)
Run the dashboard locally using Streamlit:

streamlit run dashboard/streamlit_app.py


Open in browser: http://localhost:8501

🧑‍💻 About the Project
This project is designed to showcase skills in Python, Data Engineering, and Data Visualization. It integrates multiple stages of a data pipeline, including extraction, transformation, and loading of data, and provides interactive dashboards for insights.

🛠 Key Features

✅ Full ETL pipeline (extract, transform, load)

✅ Interactive dashboard with Streamlit

✅ Automated data profiling using Sweetviz and YData

✅ Interactive charts with Plotly

✅ Correlation analysis and feature insights

✅ Option to generate sample datasets

✅ Docker support for containerized deployment

📦 Project Structure

src/ – Core ETL scripts: extract.py, transform.py, load.py, etl_run.py, config.py

scripts/ – Data generation scripts

dashboard/ – Streamlit app, HTML reports, testing scripts

infra/ – Dockerfile and docker-compose.yml for containerization

logs/ – ETL logs

requirements.txt – Python dependencies

⚡ Tech Stack / Dependencies

Python 3.10+

Pandas, NumPy

Scikit-Learn

Streamlit, Plotly

Sweetviz, YData Profiling

Matplotlib, Seaborn
